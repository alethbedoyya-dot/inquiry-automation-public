# Public Demo Assets

This directory is reserved for future public-facing demonstration materials.

Only add images or files that were produced by a real run and then manually
desensitized. Before committing an asset, remove or mask account information,
URLs, cookies, tokens, project names, addresses, contacts, supplier details,
business identifiers, attachments, and browser profile paths.

Do not add screenshots of real company systems, real quotation documents, or
fabricated interfaces that resemble a company system. If no verified sanitized
asset is available, leave this directory with this README only.
